# תבנית — אתר מעקב תרגילים

אתר שממפה את תרגילי הקורס למטריצה של **נושא × יחידה**: כל שאלה יושבת בהצטלבות
של הנושא שלה והשבוע שבו נלמדה, עם התרגיל והפתרון נפתחים בתוך הדף, סימון
"נפתר", דגלים לשאלות לחזור אליהן, סינון וחיפוש. ההתקדמות נשמרת בדפדפן.

עמוד אחד, בלי שרת ובלי תלויות. עולה ל-GitHub Pages כמו שהוא.

---

## איך מתחילים

1. **Use this template** למעלה ← רפו חדש משלכם
2. `git clone` של הרפו החדש
3. לפתוח את התיקייה ב-**Claude Code**
4. לזרוק פנימה את הסילבוס, התרגילים והפתרונות, ולכתוב:

   > תבנה לי אתר תרגילים מהחומרים האלה

זהו. הסקיל שבתוך הרפו יבקש את מה שחסר, יציע מבנה, יראה כמה עיצובים לבחירה,
יסווג את השאלות ויעלה את האתר.

### מה כדאי לשלוח לו

**חובה:**
- **הסילבוס** — צילום מסך, PDF, קישור, או סתם לכתוב במילים שלכם מה בחומר
  ואיך הקורס מחולק. ממנו נגזר כל המבנה.
- **התרגילים** — קובץ או צילום לכל שאלה זה הנוח ביותר, אבל PDF של סט שלם גם
  עובד. שמות הקבצים לא משנים.
- **מה בחומר למבחן** — אם יש חלקים שירדו, להגיד. אחרת האתר יציג חומר מיותר.

**אם יש — שווה מאוד:**
- פתרונות
- מבחני עבר והפתרונות שלהם
- דף נוסחאות
- שם הקורס, המוסד ומספר הקורס

**טיפ לפתרונות:** הכי מהיר להפנות את צילומי המסך ישירות לתיקייה ולצלם לפי
הסדר —

```bash
defaults write com.apple.screencapture location "$PWD/solutions" && killall SystemUIServer
```

לחזרה למצב הרגיל: `defaults delete com.apple.screencapture location && killall SystemUIServer`

## לעשות את זה ידנית

הרפו נבנה כך שאפשר גם בלי Claude.

```bash
node tools/build.js      # בונה את index.html
python3 -m http.server   # לראות אותו
./update.sh "תיאור"      # build + commit + push
```

עורכים שני קבצים בלבד:

**`data/course.json`** — איך האתר נראה ואיך הוא מחולק: כותרת, ערכת צבעים,
האשכולות והנושאים, ואיך נקראת היחידה (שבוע / פרק / יחידה).

**`data/questions.json`** — היחידות והשאלות.

שניהם מתועדים מבפנים בשדות שמתחילים ב-`_`.

תמונות:
```
exercises/<id>.png              התרגיל
solutions/<id>.png              פתרון בעמוד יחיד
solutions/<id>-1.png, -2.png    פתרון בכמה עמודים
```

**לא עורכים את `index.html`** — הוא תוצר build ונדרס בכל הרצה.

## ערכות צבעים

שש ערכות ב-`tools/themes.json`. כל אחת היא גוון אחד שממנו נגזרים כל האפורים,
צבע הדגשה, וגרף התקדמות משלה בראש הדף:

| ערכה | מתאים ל־ | הגרף |
|---|---|---|
| `violet` | קוונטים, פיזיקה מודרנית | שתי עקומות הסתברות קלועות |
| `teal` | אלקטרומגנטיות, גלים | גל אלקטרומגנטי |
| `indigo` | מתמטיקה, חדו״א | תנודה דועכת שמתכנסת |
| `amber` | מערכות ספרתיות, מדעי המחשב | אות ריבועי של שעון |
| `rose` | ביולוגיה, כימיה | עמודות |
| `slate` | ניטרלי — כל מקצוע | עמודות |

הגרף ניתן להחלפה בנפרד דרך `meter` ב-`course.json`.

## הכלל היחיד שחשוב במבנה

**נושא צריך לחזור ביותר מיחידה אחת.**

אם כל נושא שייך ליחידה אחת בדיוק, המטריצה יוצאת אלכסון ריק — רוב התאים מקף —
ואין בה שום מידע מעבר לרשימה רגילה. אל תיקחו את כותרות השבועות ותהפכו אותן
לנושאים; חפשו מושגים רוחביים שחוזרים לאורך הקורס. אלה שנותנים למטריצה את
הערך שלה.
